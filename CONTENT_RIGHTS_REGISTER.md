# AEM Content Rights Register

**Register version:** 1.1  
**Updated:** 20 November 2026  
**Governing policy:** [CONTENT_RIGHTS_POLICY.md](./CONTENT_RIGHTS_POLICY.md)

This is the central tracking register for third-party content used or proposed for AEM. A listing is not automatically an approval. The status applies to the exact use described and must be revisited if the asset, source terms, or use changes.

## Status key

- **APPROVED** — documented evidence covers the exact planned use.
- **CONDITIONAL** — the license permits the planned use in principle, but listed asset-level checks or implementation conditions remain.
- **HOLD** — source, ownership, permission, or the intended use is not sufficiently established; do not publish/use.
- **NOT PRESENT** — an earlier proposed entry was not found in the current source code; do not describe it as published.
- **REMOVED** — no longer used; retained for audit history.
