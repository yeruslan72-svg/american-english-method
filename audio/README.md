# Audio library

This folder stores original American English Method lesson recordings.

Start with [AUDIO_LIBRARY.md](../AUDIO_LIBRARY.md) for naming, upload, and review rules.

Create one folder per lesson, for example `lesson-01-glass`. Keep MP3 filenames numbered and descriptive. Do not upload third-party audio unless its reuse rights have been checked and recorded in `AUDIO_SOURCES.md`.
